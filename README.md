# SuperShop
SuperShop is a modern web application for online shopping that provides users with a convenient and intuitive interface for browsing and purchasing products.

The application features product filtering by categories, allowing users to quickly find relevant items. Products are displayed as dynamically generated product cards containing essential information such as name, price, and images. 

Users can:

* view detailed product pages with extended information;

* add products to a shopping cart and manage its contents;

* log in to access personalized functionality. 
## How to run a project locally
1. Clone repository:
   git clone https://github.com/gollorionna/webpack.git
2. Navigate into the project folder:
   cd webpack
3. Install dependencies:
   npm install / yarn i
4. Build project:
   npm run build:dev
5. Start project:
   npm run start

## Technologies Used 
1. Typescript
2. Redux Toolkit
3. RTK Query
4. Webpack
5. Rest API(dummyJSON)
